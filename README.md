# Tactical Grid

A tactical grid editor for tabletop RPGs and strategy games.  
Generate dungeons, place heroes, and explore with fog of war.

## Features

- Procedural dungeon generation (rooms + corridors)
- Interactive canvas with zoom and pan
- Drag-and-drop hero placement (3 heroes + 1 monster)
- King-like movement (1 cell in any direction)
- Fog of war (revealed around heroes, remembered)
- Editable hero stats (name, HP, attack, defense)
- Autosave to localStorage
- Turn counter

## Tech Stack

- React
- TypeScript
- Vite
- HTML5 Canvas

```bash
